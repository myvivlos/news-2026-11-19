A numbered front page headed "THE WORLD IN ONE DAY" for Thursday 19 November 2026, with a huge date
masthead, 13 illustrated sections tagged by region, and a world map whose pins carry the same numbers
as the sections. An "Also on the day" list adds 23 further headlines, and a four-figure strip closes
the page. The program writes the finished 1024x1024 image, unchanged, as `entry.png`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node --experimental-strip-types main.ts
```

## What the judge sees

The judge reads exactly the bytes of `entry.png`. The file must stay a whole PNG or JPEG of at most 1 MiB and 1024x1024.
