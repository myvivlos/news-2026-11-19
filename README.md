A heavy black-nameplate front page headed "THE WORLD IN ONE DAY" for Thursday 19 November 2026: 42
sourced headlines in three tight columns, a world map panel marking where each story happened, and
a strip of four figures. The program writes the finished 1024x1024 image, unchanged, as `entry.png`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node --experimental-strip-types main.ts
```

## What the judge sees

The judge reads exactly the bytes of `entry.png`. The file must stay a whole PNG or JPEG of at most 1 MiB and 1024x1024.
